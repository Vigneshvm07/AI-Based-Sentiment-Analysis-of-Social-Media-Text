# AI-Based Sentiment Analysis of Social Media Text

## Project Overview

AI-Based Sentiment Analysis of Social Media Text is a web-based
application designed to analyze social media posts, comments, reviews,
and other textual content.

The system identifies the sentiment expressed in the text and classifies
it into three categories:

- Positive
- Negative
- Neutral

The project demonstrates the use of Artificial Intelligence concepts,
Natural Language Processing, and web technologies.

---

## Objectives

The main objectives of this project are:

1. Analyze social media text.
2. Identify positive and negative opinions.
3. Classify text into Positive, Negative, or Neutral sentiment.
4. Display confidence scores.
5. Provide an interactive sentiment dashboard.
6. Maintain recent analysis history.
7. Provide a simple and professional user interface.
